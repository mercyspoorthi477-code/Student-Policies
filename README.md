# Autonomous MirAI Student Policy Advisor

A source-grounded RAG application for the MirAI School of Technology Student Policy Handbook 2026. It uses FastAPI, Streamlit, LangChain LCEL, MultiQueryRetriever, Google Gemini, and persistent ChromaDB.

## Setup on macOS

```bash
python3 -m venv .venv
source .venv/bin/activate
python3 -m pip install --upgrade pip
python3 -m pip install -r requirements.txt
```

Create `.env` from `.env.example` and add your real Google API key:

```bash
GOOGLE_API_KEY=your_real_key_here
```

## Run the Backend

```bash
source .venv/bin/activate
python3 -m uvicorn backend:app --reload
```

Swagger docs: http://127.0.0.1:8000/docs

Useful endpoints:

- `GET /health` checks API readiness and vector-store status.
- `POST /ingest` uploads and indexes a PDF through multipart/form-data.
- `POST /ingest/default` indexes `Mirai_SoT_Policy_Handbook_2026.pdf` from this folder.
- `POST /chat` answers JSON questions using retrieved handbook context.

## Run the Frontend

Open another terminal:

```bash
source .venv/bin/activate
python3 -m streamlit run frontend.py
```

Use the sidebar uploader to ingest the handbook PDF before chatting. The UI does not create fake answers when the backend is offline or the vector store is empty.

## Run Evaluation

```bash
source .venv/bin/activate
python3 evaluate.py
```

`evaluate.py` runs the four required policy questions through the real RAG chain, sends each answer and retrieved context to a judge LLM, and writes `rag_eval_scores.csv` with:

```text
question, generated_answer, retrieved_context, score, reasoning, evaluation_status
```

If `GOOGLE_API_KEY` or model access is unavailable, the CSV is still written with accurate `pending` or `failed` statuses instead of fabricated scores.

## Architecture

1. `PyPDFLoader` loads the handbook PDF.
2. `RecursiveCharacterTextSplitter(chunk_size=1000, chunk_overlap=200)` creates chunks.
3. `GoogleGenerativeAIEmbeddings` uses `text-embedding-004`.
4. Chroma persists vectors locally in `chroma_db/`.
5. `MultiQueryRetriever` expands questions for retrieval.
6. `ChatGoogleGenerativeAI` uses `gemini-3.8-flash` at temperature `0.0`.
7. LCEL composes the grounded answer chain.
8. Responses include source/page metadata where available.

## Grounding Rules

The assistant must answer only from retrieved handbook text. If the retrieved context is insufficient, it must say so. It must not invent fines, email addresses, deadlines, exemptions, or disciplinary rules.

## Limitations and Troubleshooting

- The requested model IDs are used exactly. If Google does not support `gemini-3.8-flash` or `text-embedding-004` for your account, the app reports the exact API/model failure instead of silently substituting another model.
- If `/chat` says the vector store is empty, run `/ingest/default` from Swagger or upload the PDF in Streamlit.
- If `zsh: command not found: pip` appears, use `python3 -m pip`, not bare `pip`.
- Do not commit `.env`, `.venv/`, or `chroma_db/`; they are ignored.

## GitHub Publishing

Before publishing, confirm `.env` is not tracked, run a syntax check, and commit only source files, requirements, README, `.env.example`, `.gitignore`, the handbook PDF if your assignment expects it, and any real `rag_eval_scores.csv` generated by your run.
